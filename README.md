## 🚀 Featured Projects

### 🌾 AgriBot: Autonomous Agricultural Robot
*Final-year project at SIAF / TuniBot*

Full-scale autonomous robot for field operations.
- ROS 2 Jazzy + Nav2 navigation, EKF sensor fusion (GPS, IMU, wheel odometry), AMCL localization
- Custom RP2350 firmware: Modbus RTU motor control, PID with anti-windup, encoder odometry
- Coverage path planning (boustrophedon) from a Flutter mobile app + Flask backend
- Full Gazebo / RViz simulation of the pipeline

### ⌚ VitalTrack: AI-Powered Smart Health Watch
*Academic project at ENET'Com*

Real-time connected smartwatch for continuous health monitoring.
- Monitors heart rate, SpO₂, blood pressure, glucose level, physical activity and stability state
- ESP32 + physiological sensors (MAX30100, MPU6050, AD8232)
- Flutter mobile app with Firebase Realtime Database & Firestore
- FastAPI backend serving ML models (TensorFlow Lite, Random Forest, regression, neural networks)

### ⚖️ Self-Balancing Robot
*Summer research internship at ENET'Com lab (2025)*

Design and intelligent control of a two-wheeled self-balancing robot.
